# Why there is no front end

The useful core is a private record of opportunities, next actions, permission and placement evidence. Ask an agent for the due work or a client report; it runs the CLI and shows actual records. Read-only HTML worksheets provide a view without another application to operate.

A screen offers visual drag and drop, inbox conversation views, live collaboration and mobile convenience. This base has none of those. It also does not include a prospect database, contact enrichment, delivery reputation management, automatic monitoring or email sending. Manual observations remain dated assertions with evidence references, not independently verified web results.

This fits an agency with an existing publisher list and an operator who wants control over reporting and review. It does not replace every Pitchbox feature. Enterprise DNA can build the needed screens, access controls and licensed connections into a custom version after agreeing scope. No such connection is included or implied by the free base.
