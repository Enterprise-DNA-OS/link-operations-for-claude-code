# permission

Read CLAUDE.md and docs/cli.md. Replace placeholders with the operator's supplied facts.

```bash
node scripts/links.mjs permission "<contact>" --evidence="<source and scope>" --date=YYYY-MM-DD --actor="<operator>"
```

Use only recorded express permission for this sender and purpose. A public email address is not evidence. Never reinstate a suppressed address through direct database edits.

Ambiguous matches must be shown to the operator, never silently selected. Keep client information and generated documents private.
